# Cuboards — premium product roadmap

_Last reviewed: 2026-10-09_

Andre asked to keep these improvements on file and implement in priority order.

## Tier 1 — subscription-worthy

1. **Cloud account & sync** (Supabase) — jobs follow the installer across phone, shop PC, laptop.
2. **Business profile on PDFs** — logo, VAT/CK, bank, contact on client quote and optional cut-list letterhead.
3. **Job pipeline** — quote sent → approved → in build → done; follow-up dates.
4. **PayFast tiers** — free (limited jobs, local) vs Pro (sync, branded PDF, unlimited).

## Tier 2 — pro depth

5. **Visual sheet maps** — **in progress (2026-10-09)** — diagram per sheet from nesting.
6. **Share quote link** — read-only client view + optional accept.
7. **Quote revision history** — v1/v2/v3 on one job.
8. **Room / area grouping** — kitchen vs scullery on scope and cut list.
9. **Built-in template library** — common base/wall/drawer units for fast onboarding.
10. **Pre-export checklist** — warnings gate before PDF.

## Tier 3 — later

Bedroom modules (hanging rail, etc.), CSV/Excel factory export, WhatsApp share, markup layer, team seats.

## Packaging sketch (ZAR)

| Plan | ~Price | Includes |
|------|--------|----------|
| Free | R0 | Local, few jobs, basic PDF |
| Pro | R199–349/mo | Sync, unlimited, branded quote, pipeline, templates |
| Team | ~R499/mo | Shared defaults, 2–3 users |

## Build order agreed

Start with **visual sheet maps**, then revisit Tier 1 (sync + branded PDF) when ready.
